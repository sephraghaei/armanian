# Desktop UX/UI refinement

## Goal
Improve the desktop homepage so it feels more polished, spacious, and easier to scan while preserving the current Persian RTL content, Attio-inspired visual direction, and mobile behavior.

## Changes
- Refine the desktop header into a cleaner, wider navigation bar with balanced brand, links, account action, and stronger active/focus states.
- Rework the first screen’s spacing and proportions so the headline, search, and actions form a clearer hierarchy and the next section remains visible.
- Remove the leftover decorative wave layers and use quiet section borders/background bands instead.
- Standardize desktop section widths, heading alignment, vertical rhythm, and content density across departments, learning paths, about, videos, contact, and footer.
- Improve card grids with equal heights, better typography, clearer clickable states, subtle lift animation, and more consistent action placement.
- Make the video area and contact area use desktop space more effectively with balanced side-by-side layouts.
- Simplify the footer and remove non-functional links so desktop navigation feels intentional.
- Preserve keyboard focus visibility, reduced-motion behavior, contrast, and RTL alignment.

## Verification
- Check the homepage at 1280px and a wider desktop viewport for alignment, overflow, text fit, and interaction states.
- Confirm the homepage loads without browser errors and the project build remains clean.

## Technical details
- Changes will stay within homepage presentation files and shared styling; enrollment, authentication, database, and admin behavior will not change.
- Existing semantic color tokens and shared buttons will be reused rather than introducing hardcoded colors.
